# Organizing an Experiment Folder into the Report Layout

Use when the user points at one course-experiment folder and asks to tidy it — 「整理一下文件夹」 / 「把这个文件夹归一下类」. The target layout is already fixed; this skill owns the migration and the proof that moving the files changed nothing.

## Steps

1. **Read the layout authority, then inventory the folder.** The layout is defined in the operator's `lab-report` skill (固定路径): the experiment root keeps 讲义 / 预习报告 / 报告指引 / 坐标纸 / 打印/, and `<实验根>/实验报告/` holds the 成品 report (骨架 docx and filled html/pdf at its top level) with `数据/`, `代码/`, `图表/` beneath. `ls -laR` the folder, and `ls -1` a sibling that already follows the layout as the worked example.
   Completion: every existing file has a named destination.

2. **Classify before moving: course materials stay at the experiment root.** Only report artifacts go under `实验报告/` — csv/txt into `数据/`, figures into `图表/` (rename to the skill's `fig1_xxx.png` convention), `*.py` into `代码/`, skeleton and filled report at the top. Do not rename the teacher's or the course's files, and do not introduce a second naming scheme.
   Completion: no course material moved, and no course file renamed.

3. **Move, then repath every script before its first run.** A project script that resolved I/O from its own location (`HERE = os.path.dirname(os.path.abspath(__file__))`, then `os.path.join(HERE, "原始数据.csv")`, `savefig(os.path.join(HERE, ...))`, `open(os.path.join(HERE, ...html))`) re-points to `代码/` the moment it moves there — it would read a csv that no longer sits beside it and drop new artifacts inside `代码/`. Route every self-relative path through the report root:

   ```python
   HERE = os.path.dirname(os.path.abspath(__file__))     # 实验报告/代码
   REPORT_DIR = os.path.dirname(HERE)                     # 实验报告
   DATA_DIR = os.path.join(REPORT_DIR, "数据")
   FIG_DIR = os.path.join(REPORT_DIR, "图表")
   DEFAULT_CSV = os.path.join(DATA_DIR, "原始数据.csv")
   ```

   The HTML generator must emit `<img src="图表/<name>.png">` — relative to the HTML file, not `os.path.basename(fig)`. Grep the rest (`savefig`, `open(os.path.join(HERE`, `basename`, `"原始数据.csv"`) so no self-relative use is left; the same constants make the script runnable from any CWD.
   Completion: no script resolves input or output from `HERE` alone.

4. **Audit hard-coded 测压管配对 while you are in the code.** An older helper written against the report template's *printed* label breaks once the pairing is corrected — measured: a pair list holding (11,10) and (13,12) made `math.sqrt` raise `ValueError: expected a nonnegative input, got -0.039204`, because the axis (总压) reading of those sections is the higher-numbered tap (axis 6、9、11、13, static 5、8、10、12). Align every script with the shipped report's own pairing, not the template's printed 位置 list.
   Completion: every script runs, and its printed numbers match the shipped report.

5. **Re-run from the new location and prove the artifacts did not change.** Exit status 0 is not proof:
   - **figure** — `md5sum` against the pre-move copy; identical bytes are expected (measured: `7b817a6c…` both sides);
   - **HTML** — `diff` should show only the asset path you rewrote; anything more means the generator also changed content;
   - **PDF** — the regenerated bytes differ by embedded creation metadata (measured 518115 vs 518111 B), so compare size and the numbers inside, never the hash. `pdftotext` is not installed on this host; read text with `pymupdf` `page.get_text()`.
   Completion: figure md5 matches, the HTML diff is path-only, and the PDF's numbers match.

6. **Write `代码/readme.md`, then report the tree and the one cleanup item.** The readme carries the folder map, each script's purpose and run command, and the data口径 the folder depends on. `__pycache__` is regenerable cache, but removing it is still a deletion — list it and wait for the user's confirmation (WSL deletes on a Windows mount do not use the Recycle Bin); moving it under `代码/` is the non-destructive way to clear the root.
   Completion: the readme exists, and the reply carries the tree, the verified checks, and the pending delete item.

## Notes

- The layout definition lives in the operator's `lab-report` skill; this skill owns applying it to an existing folder and proving the move. Saving or deleting a new teacher handout is `lab-handout-archive`; reading data off a photo/PDF is `lab-data-intake`; rendering a PDF is `report-pdf-export`.
- Trigger on an explicit 整理/归档 ask about one experiment folder. Do not reorganize a folder the user only asked you to read or to save a file into.
