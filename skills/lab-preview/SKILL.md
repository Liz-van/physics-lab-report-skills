# 大物实验预习报告生成（大学物理实验）

触发词：`实验预习`

## 与 `lab-report` 的关系

- 本 skill 是 `lab-report` 的**子流程**：只产出「预习报告」部分。
- **共享**代码与规范（相对路径引用，勿复制）：
  - 脚本：`../lab-report/scripts/`
  - 规范：`../lab-report/references/`
  - 个人信息：`../lab-report/assets/profile.json`
- 通用规则（路径、骨架来源、公式、拿不准就问）全部继承 `../lab-report/SKILL.md`。

## 产出边界

只生成以下章节，**不**做实验内容/记录/数据处理/讨论：

1. 实验目的
2. 仪器用具（表格：编号/名称/数量/主要参数）
3. 原理概述（含必要公式，Word 原生 OMML）
4. 实验前思考题

## 流程

0. 盘点：`<实验根>/实验报告/` 是否已有预习部分（引用 `../lab-report/scripts/report_inspect.py`）。
1. 解析讲义 + 指引，抽原理要点与思考题。
2. 撰写上述 4 节；只补缺失，已有保留。
3. 装配 docx：骨架 = 已有实验报告 docx（空白/部分完成）；**不存在就先问用户**。
4. 自检 + 归档到 `<实验根>/实验报告/实验报告.docx`。

## 路径（同 lab-report）

`<实验根目录>/<实验名>/实验报告/`
