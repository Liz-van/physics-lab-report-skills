# 文字与风格规范

## 防 AI 味 / 防抄袭（指引明确扣分）

- **禁止照搬讲义原文**：原理概述要重组语序、用自己的表述，保留公式与关键定义。
- 避免套路句：不要「首先…其次…最后…」「综上所述」「值得注意的是」「总而言之」堆叠。
- 不要空话：写具体操作、具体数值、具体现象，不写「保证了实验的准确性」这类无信息句。
- 数据描述要落到数：写「末温稳定在 12.4 ℃，3 min 内漂移 < 0.1 ℃」，不写「温度基本稳定」。
- 思考题：先答结论，再给依据/推导，最后必要时补实验现象。
- **简洁优先**（误差分析/改进办法）：
  - 每条 1~2 句，不展开推导；改进办法 4~5 条，不引入讲义外的方法。
  - 不加方向性推断（如「与①方向相反」「使 L 系统性偏大」）。
  - 不往分析里塞统计数字（如「相对标准不确定度约 3.7%」），数字放表格。
  - 不写「三种方案相互一致」这类无信息判断。
- 中文标点全角；公式与数字用 Times New Roman；正文用宋体，标题黑体/宋体加粗（跟随骨架模板）。

## 公式写法（硬规则，2026-09-16）

- 所有公式用 **LaTeX** 交给 `scripts/omml.py` 生成原生 OMML；**不得用 Unicode 字符"手搓"公式**。
- LaTeX 源码必须**纯 ASCII**；中文只能写在 `\text{...}` 里（如 `T_{\text{实际}}`）。

| 想写 | 不要用 | LaTeX 写法 |
|---|---|---|
| m₀、T₁ | 下标字符 `₀₁₂` | `m_0`、`T_1` |
| 10⁻¹、u² | `⁻¹` `²` | `10^{-1}`、`u^2` |
| √2、√3 | `√` | `\sqrt{2}`、`\sqrt{3}` |
| 3×10² | `×` | `3\times10^2` |
| ≈ | `≈` | `\approx` |
| T₀−T₁ | `−`（U+2212） | `T_0-T_1`（普通减号） |
| g·℃ | `·` | `\cdot` |
| 0 ℃ | `°` | `0^\circ\mathrm{C}` |
| T₀′ | `′` | `T_0'` |
| ΔT、Δm | 直接敲 `Δ` | `\Delta T`、`\Delta m` |
| μ、λ、ρ | 希腊字母直敲 | `\mu`、`\lambda`、`\rho` |
| 单位 | `L(J·g⁻¹)` | `L/(\mathrm{J\cdot g^{-1}})` |

- 正文/表头里的**任何物理量符号一律写成公式**：不得出现 `m_0`、`T_0`、`T₀`、`u_A`、`ΔT`、`L₁.₁` 这类纯文本。
- 骨架里已有的公式格/占位只填不删（`docx_io.fill_omml_placeholder`）。
- 生成物不得带本机字体名（如 Noto Sans CJK SC）；`omml.py` 自动清掉字体声明，公式字体跟随文档默认（Cambria Math + 宋体）。

## 术语与符号

- 物理量符号与讲义一致；首次出现给定义与单位。
- 单位用国际符号（℃、g、s、m、kg）；数值与单位间留空格。
- 百分号、度号正确（相对误差 2.3%，倾角 30.0°）。

## 有效数字

- 直接测量：按仪器分度值/分辨率保留，估读到最小分度下一位（按课程要求）。
- 运算：乘除看有效数字最少者，加减看末位最高者；不确定度单独规则（见 `uncertainty.md`）。
- 结果表达：`x = (x̄ ± U) 单位`，U 保留 1~2 位有效数字。
