# 大学物理实验 报告结构

## 报告组成（三部分 + 封面）

1. **封面**：课程名 / 专业·年级 / 姓名·学号 / 日期 / 教师签名 / 成绩栏（预习·记录·分析·总成绩）
2. **预习报告**
   - 实验目的
   - 仪器用具（表格：编号 / 名称 / 数量 / 主要参数（型号、量程、精度））
   - 原理概述（热力学第一定律、公式推导；步骤要点）
   - 实验前思考题
3. **实验记录**
   - 实验内容、步骤、结果、现象
   - 记录表格（提前设计好表头）
   - 原始数据（学生手写，本 skill 只做排版与计算）
4. **分析讨论**
   - 数据处理（按规范呈现图、表）
   - 不确定度评定（A/B 类 + 合成 + 扩展 k=2）
   - 误差来源分析
   - 实验后思考题
   - 结论

## 分值与篇幅参考（不写进报告）

分值只用于判断哪节该写多少。常见权重：

- 实验目的 ~4 分 → 3~5 行
- 仪器用具 ~4 分 → 完整表格
- 原理概述 ~10 分 → 主体，含公式推导
- 实验前思考题 ~8 分 → 逐题回答
- 实验内容/步骤/结果/讨论 → 最大头（如 54 分）
- 后思考题 → 逐题回答

## 表格规范

- 表题：`表 N　<说明>` 用全角空格，放**表格上方**居中；含环境量时写明（如「（室温 T = 19.8 ℃）」）。
- **骨架表格只填不改**：维度、合并、列宽、表头文字、条目名称都沿原样；只往空单元格里填内容。
  - 例：仪器用具表骨架是 2×4（编号 1~6 堆在第一格），**不要拆成 7×4**；名称用骨架原文（` MS6514 测温仪`、`配两对K型热电偶`）。
  - 骨架容量不够时才扩展/转置，并在 `代码/readme.md` 写清理由。
- **表头里的物理量符号与单位必须写成公式**（OMML），如 `mc/g`、`T0/℃`、`L/(\mathrm{J\cdot g^{-1}})`；
  不得写成 `m_c / g` 纯文本。骨架里已有的公式格只填不删。
- 列名用最短词（「结果」不要写成「结果表达」）；表头不加「（每 30 s 记录一次）」这类说明。
- 表格下方**不写"注："**（划改、来源、取值理由都不写）。
- T-t 记录表：骨架是 8×15（时间在行、采样在列，最多 14 个采样点）；30 s 采样、上万秒的数据放不下，
  可以转置成「每个采样点一行、每组两行（时间/s、温度/℃）」（本实验即 33×8，用户认可）。

## 步骤规范

- 「步骤：」单独一段；①②③… 每条一段，**不要把多条挤在一段里**（`report_check.py` 会报「步骤分条」）。
- 步骤内容用骨架/讲义原文，**不自行扩写技术细节**（采样间隔、搅拌方式等不需要在步骤里解释）。

## 图表规范

- 表：`表 1 <说明>` 放**表格上方**居中
- 图：`图 1 <说明>` 放**图上方**居中
- **应要求补充的图只放图**：不加自造图题、不写解释段落（图题只给骨架已有或用户明确要求编号的图）。
- 图宽统一 13.00 cm（本实验为 13.00×8.23 cm）；**插图必须锁定纵横比**，裁剪用图片框的裁剪而不是拉伸。
- 图内中文用宋体、数字/公式用 Times New Roman
- 无网格线；有坐标轴标签与单位；数据点用标记，连线/拟合线区分
- 300 dpi PNG
- 正文按顺序引用（「如图 1 所示」「见表 2」）

## 附件区（不由 skill 生成）

- 报告末尾的附件（附件1 实验记录手写扫描、附件2 预习报告签字、附件3 原始温度数据）由 **用户手工粘贴**。
- skill 只负责产出「附件3 原始温度数据」所需的图表/数据，并在回报里提醒他自行插入。

## 数据处理流程

1. 数据来源标注（原始记录页/照片编号）
2. 原始数据表 → 中间量计算表 → 结果表
3. 逐量算不确定度（A 类：贝塞尔/极差法；B 类：仪器误差限）
4. 合成标准不确定度 → 扩展不确定度（k=2）→ 结果表达 `x = (x̄ ± U) 单位`（U 取 1~2 位有效数字，x̄ 末位与 U 对齐）
5. 误差来源分析（系统 + 随机，结合实验现象）
6. 结论（与公认值比较，相对误差）
