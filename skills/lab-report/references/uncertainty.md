# 不确定度评定（标准流程）

## A 类（多次测量，统计）

- n ≥ 6 用贝塞尔：`u_A = s / sqrt(n)`，`s = sqrt(Σ(xi-x̄)²/(n-1))`
- n < 6 且要求用极差法：`u_A = (x_max - x_min) / d_n`
  - 极差系数 d_n：n=2→1.13, 3→1.69, 4→2.06, 5→2.33, 6→2.53, 7→2.70, 8→2.85, 9→2.97, 10→3.08
- 单次测量：u_A 不适用，只评 B 类

## B 类（仪器/示值，非统计）

- 一般 `u_B = Δ_instr / sqrt(3)`（均匀分布），Δ_instr = 仪器误差限
- 仪器误差限来源优先级：讲义/说明书 > 课程约定 > 分度值 × 系数（模拟仪表常取 分度值/2 或 ±0.5 分度，数字仪表取分辨率）
- 若同时给出分辨率与准确度等级，按课程约定

## 合成与扩展

- 直接量：`u_c = sqrt(u_A² + u_B²)`
- 间接量 `y = f(x1, x2, ...)`：
  `u_c(y) = sqrt( Σ (∂f/∂xi · u(xi))² )`
  - 常用简化：乘除式用相对不确定度平方和
    `u_r(y) = sqrt( Σ (p_i · u_r(xi))² )`（指数形式）
- 扩展：`U = k · u_c`，**k = 2**（置信概率 ~95%）
- 结果表达：`x = (x̄ ± U) 单位`；U 与 x̄ 末位对齐；另给相对不确定度 `E = U/x̄ × 100%`

## 有效数字规则

- u_c、U 一般保留 1~2 位有效数字（首位为 1 或 2 时可留 2 位）
- x̄ 的末位与 U 对齐
- 中间计算多留 1~2 位，最终再修约
