## A. 开做前「口径确认单」（必填，逐条问用户，问完再动手）

1. **总压管 / 静压管逐对编号**（含变径段行序，例：(静 5, 总 6)、(静 11, 总 10)…）
2. **各测压管管轴高程 z** 是否相同；不同则要到各层 z（或明确「z 不用管」）
3. **水头线的流速口径**：断面平均流速 u = Q/A ／ 轴心流速 ／ 联立解
4. **变截面段是否联立解**（如文丘里 1-2：连续性 v₁A₁ = v₂A₂ + 伯努利，解出 (h₁−h₂) = ((d₁/d₂)⁴−1)·v₁²/2g）
5. **各列有效数字位数**（流速 / 水头 / 比值分别几位）
6. **报告模板里印的样板编号是否照抄**——**模板印的编号不是口径**（例：模板表 2 印「毕托管位置 6、9、10、12」，
   实际总压管是 6、9、11、13），一律以现场确认为准
7. 附加交付项：是否要**速度水头线**、是否标两线间距、是否要 docx 版、是否要「表 1 留空手抄版」

## B. 识图录入后的「物理自洽三查」（硬规则）

1. **Δh = 总压读数 − 静压读数 > 0**（同一截面）
2. **Δh ∝ Q²**：各工况 Δh/Q² 的相对离散 < 5%
3. **c = √(Δh / (v̄²/2g)) ∈ 1.05~1.35**（湍流；层流/过渡更大）

任一不过 → **停下来回读给用户确认，禁止擅自改动数据**（哪怕物理上明显读反）；
识图原样另存 `原始数据-识图原样.csv`，修正只写进 `原始数据.csv`。

## D. PDF 路线（本机无 Word / LibreOffice）

1. `python-docx` 填模板 → docx；需要打印版时：
2. **HTML + `weasyprint`（`/usr/local/bin/weasyprint`）→ PDF**；
   CSS：`@page { size: A4; margin: 18mm 16mm; }`，字体 `"Noto Sans CJK SC"`。
3. **matplotlib 先设 CJK 字体**，否则中文变方块：
   ```python
   plt.rcParams["font.sans-serif"] = ["Noto Sans CJK SC"]
   plt.rcParams["axes.unicode_minus"] = False
   ```
4. 交付：`message(action="send", media=<绝对路径>, message=...)`。

## E. 讲义图形信息提取（图里的编号/尺寸）

1. `pymupdf` 按 300 dpi 渲染该页 → 按图区裁切（可再放大 1.4×）另存 PNG；
2. 交视觉模型逐条读，提示词：
   「逐条转录图中所有编号数字及其位置、管径标注（d8/d4/d10）、尺寸数字、说明文字；
     测压管有无弯头/管口朝向差异；看不清就说看不清，不要推测」；
3. 读到的编号 / 尺寸 / 管径记入 `代码/readme.md`；
4. **图上通常不标总压/静压**，仍需 A 项现场确认。
