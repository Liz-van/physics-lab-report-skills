# 大物实验报告生成（大学物理实验）

触发词：`实验报告`

## 适用与硬规则

- 只服务 `大学物理实验`。
- 默认输出 **docx**；用户要打印版/PDF 时**直接出 PDF**（本机无 Word/LibreOffice，走 HTML + `weasyprint`，见 `references/workflow-checklists.md` §D）。
- 公式一律用 **Word 原生公式（OMML）**，且**只能由 LaTeX 生成**（`scripts/omml.py` → pandoc）：
  - **禁止用 Unicode 字符"手搓"公式**：`₀₁₂` `¹²³` `⁻` `√` `×` `≈` `−` `·` `°` `′` `Δ` 这类字符**不得出现在任何输入里**，
    一律写 LaTeX：`_0` `^2` `^{-1}` `\sqrt{}` `\times` `\approx` `-` `\cdot` `^\circ` `'` `\Delta`。
  - LaTeX 源码必须**纯 ASCII**；中文只能写在 `\text{...}` 里（如 `T_{\text{实际}}`）。
  - 对照表见 `references/style-rules.md` §公式写法。
- **正文与表头里的物理量符号一律写成公式**，不得写成 `m_0`、`T_0`、`T₀`、`u_A`、`ΔT`、`L₁.₁` 这类纯文本。
- **骨架里已有的公式格/公式占位只填不删**（如表格表头 `mc/g`、`T0/℃`，正文里的空占位公式），用 `docx_io.fill_omml_placeholder()` 原位填内容。
- **骨架表格只填不改**：维度、合并、列宽、表头文字、条目名称都不动；容量不够才扩展，并在 `readme.md` 说明理由。
- 骨架里现有的文字（注意事项、思考题题干、表题措辞）保持原样，只补空缺；明显笔误可修正。
- **报告模板里印的样板编号不是数据口径**（例：模板表 2 印「毕托管位置 6、9、10、12」，实际总压管是 6、9、11、13）；一切配对以现场确认为准，见 `references/workflow-checklists.md` §A。
- 骨架里给人看的括注提示（如「(多方案并行，可增加相应的分析与讨论的内容)」）**必须删除**；`（选）`、`（可通过实验回答）` 属题干标记，保留。
- **步骤分条成段**：「步骤：」单独一段，①②③… 每条一段；内容用骨架/讲义原文，**不自行扩写技术细节**。
- 表格下方**不写"注："**（划改、取值来源等都不解释，直接取正确值）。
- 分析文字**简洁优先**：误差来源/改进办法每条 1~2 句，不加方向性推断、不塞统计数字、不写「相互一致」这类空话。
- 应要求补充的图**只放图**：不加自造图题、不写解释段落；图题只给骨架已有或用户明确要求编号的图。
- 报告里 **不写分值**；指引中的分值只用于判断篇幅与覆盖度。
- 附件区（附件1 实验记录 / 附件2 预习报告签字 / 附件3 原始温度数据）由 **用户手工粘贴**，skill 只产出图与数据、不插附件。
- **拿不准就停下问用户**（缺指引、缺骨架、缺数据、公式超纲、要不要拟合线等）。
- 完成后回报「做完了 + 路径 + 改动清单 + 待确认项」；用户要文件就**直接发**（`message` 带 `media`，微信同样）。

## 固定路径

- 实验根目录：`<实验根目录>/<实验名>/`
- 报告目录：`<实验根>/实验报告/`
  - 成品报告：`实验报告.docx`（文件名不含实验名，因为已在实验同名文件夹内）
  - 现场/随堂报告：模板 `随堂实验报告.docx` → 成品 `随堂实验报告-已填.pdf`，生成脚本与图件放同目录
  - `数据/`：原始 xlsx、清洗后 csv；手写照片放 `数据/原始记录/`
  - `代码/`：全部 `.py` 整合在此文件夹 + `readme.md`
  - `图表/`：`fig1_xxx.png`（300dpi）

## 骨架（唯一合法来源）

1. 优先用该实验已有的 **实验报告 docx**（空白或部分完成）当骨架。
2. 若不存在 → **停下问用户**，不得用「报告指引/讲义」代替骨架。

## 流程

0. **盘点**：看 `<实验根>/实验报告/` 与实验根下已有文件，判断报告已有哪些部分（引用 `scripts/report_inspect.py`）。
1. **解析**：从讲义（pdf/docx）与报告指引（docx）抽出章节、分值权重、原理要点、表格结构。
2. **大纲 + 口径确认**：列「章节 ↔ 内容 ↔ 分值权重」对照表给用户过目（可快速通道跳过）；同时按
   `references/workflow-checklists.md` §A 的**七项口径确认单**问清：总压/静压管配对、z、流速口径、
   是否联立解、各列有效数字位数、模板编号是否照抄、要不要速度水头线/docx/表 1 留空版。**没确认不动手**。
3. **撰写**：实验目的 / 仪器用具(表) / 原理概述 / 实验前思考题 / 实验内容与步骤 / 记录表格 / 数据处理 / 结果与讨论 / 实验后思考题 / 结论。**只补缺失部分，已有内容保留不动**。
4. **数据处理**（见 `references/report-structure.md` §数据处理）：
   - 输入：`openpyxl/pandas` 读 xlsx
   - 手写照片：用 `deepseek-flash`（原生多模态）读数 → **把读到的数字回读给用户确认** → 才采信；原图存 `数据/原始记录/`
   - **物理自洽三查**（识图录完立刻做，见 §B）：Δh = 总压−静压 > 0；Δh ∝ Q² 相对离散 < 5%；
     c = √(Δh/(v̄²/2g)) ∈ 1.05~1.35。任一不过 → **停下回读，禁止擅自改动数据**，原样另存 `原始数据-识图原样.csv`
   - 计算：`scripts/uncertainty.py`（A/B 类 + 合成 + 扩展 k=2）
   - 公式：任何符号/算式都用 LaTeX 交给 `scripts/omml.py`，**不要用 Unicode 字符凑公式**
   - 作图：`scripts/plot_utils.py`；**图题放图上方**；是否加拟合线/方程/R² 按实情判断，拿不准就问
   - 代码全部写入 `代码/`，并写 `代码/readme.md` 逐脚本注释
5. **装配 docx**：复制骨架 → 用 `scripts/docx_io.py` 填段落/表格（`write_mixed` 混排文字与行内公式、`fill_omml_placeholder` 填骨架占位、`set_cell_math` 写公式表头）→ 图表用 `add_centered_picture` 插入（保持纵横比）
6. **出 PDF（需要时）**：HTML + `weasyprint`（§D）；matplotlib 画图**先设 CJK 字体**，否则中文变方块。
7. **自检**：`scripts/report_check.py <成品> [--skeleton 骨架]`（章节/占位/分值/图表编号/**公式守恒**/**符号已公式化**/**公式非手搓**/提示语/游离注/**图片纵横比**/**步骤分条**/骨架文字比对）
   - 验证公式确实是原生公式：`pandoc 成品.docx -t markdown`，能把公式还原成 LaTeX 就是真公式（且能反推回我们写的 LaTeX）。
8. **归档**：写入上述目录；`readme.md` 写清数据来源与脚本用途。
9. **回报**：文件路径 + 已完成部分 + **改动清单** + 待用户手填/存疑项（含附件区），模板见 §F。
   用户要文件就**直接发**：`message(action="send", media=<绝对路径>)`（微信同样适用）。

## 规范速查

- 章节与结构：`references/report-structure.md`
- 文字与防抄袭风格：`references/style-rules.md`
- 不确定度评定：`references/uncertainty.md`
- 现场流程与口径确认（确认单 / 自洽三查 / 配置驱动 / PDF 路线 / 讲义图提取 / 回报模板）：`references/workflow-checklists.md`
- 生成脚本建议**配置驱动**（配对、截面、口径、位数、画哪几条线都进 `CFG`），改口径不改代码：`references/workflow-checklists.md` §C
- 个人信息（填封面用）：`assets/profile.json`（含固定实验地点 `lab_location`，封面「实验地点」直接填）

## 脚本

| 脚本 | 用途 |
|---|---|
| `scripts/report_inspect.py` | 盘点报告 docx 已有内容/结构 |
| `scripts/docx_io.py` | docx 读写：找段落、填表格、插图片；`write_mixed()` 文字+行内公式混排、`fill_omml_placeholder()` 填骨架公式占位、`set_cell_math()` 公式表头、`style_run()` 统一字体 |
| `scripts/omml.py` | **LaTeX → Word 原生公式（OMML）**；只接受纯 ASCII LaTeX（中文写 `\text{}`），拦截 Unicode 手搓写法 |
| `scripts/uncertainty.py` | 有效数字、A/B 类不确定度、合成与扩展 |
| `scripts/plot_utils.py` | 统一作图规范（中文、无网格、图题在上、300dpi） |
| `scripts/report_check.py` | 报告自检清单（含公式守恒、符号公式化、纵横比、步骤分条、骨架比对） |

常用片段：

```python
import docx_io as IO, omml

# 表头公式（骨架本来就这样，只填不删）
IO.set_cell_math(table.cell(0, 1), r"m_c/g")

# 正文「文字 + 行内公式」混排
IO.write_mixed(p, [
    "取水的比热 ", ("math", r"c_0=4.18\,\mathrm{J/(g\cdot{}^\circ C)}"),
    "，不锈钢内胆比热 ", ("math", r"c_1=0.46\,\mathrm{J/(g\cdot{}^\circ C)}"), "。",
])

# 原位填骨架里已有的公式占位（保留位置与周边文字）
IO.fill_omml_placeholder(p, 0, r"m_0=(m_c+m_0)-m_c")
```

用法统一：`python scripts/<name>.py --help`
