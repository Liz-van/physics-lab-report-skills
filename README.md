# physics-lab-report-skills

大学物理实验报告的六个 Agent Skills，从认读手写数据一直到出 docx 成品。

对着真实的一门课调的：讲义、报告指引、官方模板、仪器导出的数据文件都在流程里。实验报告这件事的麻烦不在写作，在于数据认错一个数字、公式变成图片、图题和骨架对不上，所以技能里卡得比较死。

## 六个技能

| 技能 | 什么时候用 | 做什么 |
|---|---|---|
| lab-report | 说「实验报告」 | 完整报告：解析讲义和报告指引、盘点并增量补全已有报告、Word 原生公式、数据处理与作图，出 docx |
| lab-preview | 说「实验预习」 | 只做预习部分：实验目的、仪器用具、原理概述、实验前思考题 |
| lab-data-intake | 手写数据照片、扫描 PDF、仪器记录要录入 | 识图读数，用物理不变量自校验，回读给你确认，再跑脚本交付 |
| blank-report-form | 要一份空白报告手写填 | 以同课程官方模板为骨架，用讲义内容搭出可填写的报告表 |
| lab-folder-organize | 实验文件夹太乱 | 按 `实验报告/{代码,数据,图表}` 归位，修脚本里靠 `__file__` 的旧相对路径，复跑证明产物没变 |
| lab-handout-archive | 收到新版指引、讲义或模板 | md5 核对入文件夹，和旧版 diff 报告变化，列旧版清单待确认后删除 |

## 几条硬规则

**公式必须是 Word 原生公式（OMML），而且只能由 LaTeX 生成。** 不许用 `₀₁₂` `√` `×` `≈` 这类 Unicode 字符手搓公式。LaTeX 源码保持纯 ASCII，中文写在 `\text{...}` 里。最后用 `pandoc 成品.docx -t markdown` 回读，能把公式还原成 LaTeX 才算数。

**数据先自洽再计算。** 录入完立刻做物理自洽三查：Δh = 总压−静压 > 0、Δh ∝ Q² 的相对离散小于 5%、c 落在 1.05~1.35。有一条不过就停下回读，不许擅自改数据。

**拿不准就问。** 缺指引、缺骨架、缺数据、公式超纲、要不要加拟合线，都停下来问，不自己编。

**只放该放的图。** 不造图题、不写解释段落；图题只给骨架里已有的，或者你明确要求编号的。

**附件不代插。** 实验记录扫描、预习报告签字、原始数据这些附件区留给你手工粘，技能只产出图和数据。

## 个人信息

`skills/lab-report/assets/profile.json` 是自动填封面用的，内容是占位符（张三 / 2025000000 / 示例大学 / 大学物理实验），改成你自己的信息再用。实验目录统一写成 `<实验根目录>`，按你的实际路径替换。

## 安装

把 `skills/` 下的六个目录复制进技能根目录：

```
~/.dsh/skills/        # DSH
~/.claude/skills/     # Claude Code
```

`lab-preview` 和 `blank-report-form` 会引用 `lab-report` 里的脚本和 references，六个目录要放在同一个技能根目录下。

## 依赖

Python 3.10 以上，需要 `python-docx`（读写 docx）、`openpyxl` 和 `pandas`（读 xlsx）、`matplotlib`（作图）、`pymupdf`（渲染扫描 PDF 和讲义页面）。

出 PDF 用 HTML + `weasyprint`，LaTeX 转 OMML 用 `pandoc`，都不是必装。matplotlib 画图前要先设 CJK 字体，否则中文变方块。
